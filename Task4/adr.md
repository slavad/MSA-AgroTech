### Решение


Часть нефункциональных и функциональных требований будут истончиком критериев для выбора между основным или альтернативным решением

| Критерий                    | Основное                                                     | Альтернативное                                              |
| --------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------- |
| F12 -- работа без интернета | Да                                                           | Нет                                                         |
| P1                          | Да                                                           | Да, возможно.                                               |
| P2 -- отклик миллисекунды   | Да                                                           | Нет. Сервера вендора должны быть близко, для такой скорости |
| Затраты на развертывание    | Выше.  Мы храним данные, мы обслуживаем софт для оборудования | Ниже. Все на плечах вендор                                  |
| Затраты на обслуживание     | Выше. По тем же причинам, что и развертывание                | Ниже                                                        |

Мы выбрали основное решение, во-первых, потому, что использование API вендоров невозможно при отключении интернета и во-вторых потому, что можно добиться отклика в миллисекунды, только если сами сервера вендора рядом находятся физически. К тому же данные и телеметрия не покидают пределы компании

### Недостатки, ограничения, риски

1. Не у всех вендоров могут быть открытые протоколы

2. Прямая интеграция -- больше проблем при развертывании. 
   Нужно поддерживать все, что надо для работы: MQTT сервера, мониторинг состояния оборудования и т.д.

3. Нестабильный WiFi -- поток данных с камер и оборудования не должен прерываться. 
   Для некоторых устройств (как поилки, кормушки, где не нужна большая скорость) можно развернуть LoRaWan.
   Но для камер придется апгрейдить WiFi или тянуть к камерам провода.
